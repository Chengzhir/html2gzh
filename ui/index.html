备用字体规则

每行一条规则，格式为 原稿字体, … => 备用字体, …

  • 字体名须写全称，不区分大小写
  • * 匹配任意数量的字符；以 # 开头的行是注释
  • 备用字体插入字体栈中 sans-serif 等通用字体名之前

检测到的公网 IP
    填写说明
    有公网 IP
    在路由器上添加端口转发：外部端口填写“公网端口”的值（留空时与本机端口相同），内部 IP 填写这台电脑的局域网 IP，内部端口填写“本机端口”的值（当前为 38960）。“公网地址”可以留空，由本工具自动检测；有域名时也可以填写域名。Windows 防火墙弹出提示时，请允许 Node.js 在当前网络中通信。
    没有公网 IP
    请使用 frp、cpolar 等内网穿透工具，把本机的 38960 端口映射到外网，再将内网穿透工具提供的地址、端口与协议分别填入对应的输入框。以 http:// 或 https:// 开头的完整地址（如 https://abc.example.com）可以整体粘贴到“公网地址”中，将自动拆分为协议、公网地址与公网端口。
    公网端口
    留空时，协议为 http 则与本机端口相同，为 https 则使用 443。本工具只提供 http；选择 https 时，由内网穿透工具或反向代理负责加密。
    检测
    保存后，本工具从这台电脑访问一次取图地址，检测能否访问；页面打开期间每 5 分钟重新检测。检测结果不一定准确，以粘贴后显示的已下载图片数为准。
    安全
    无论使用端口转发还是内网穿透，本机端口都会对外网开放。这个端口不设认证，只提供已载入文章中引用的图片；文件名为内容的哈希值，外部难以猜测。关闭本工具后即停止提供。
