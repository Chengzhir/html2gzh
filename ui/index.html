复制

载入文章后可复制。

成品会随手机屏宽等比缩放。选的这个宽度用来预览，也是还原最精确的宽度（原稿里的 @media 按它取值）；其他常见宽度会自动比对。

字体

读者手机上没有原稿字体时怎么办
px 的算大字（按 375 宽的 iPhone 算）

文中用到的字按字体、粗细（字重）、是否斜体分行列出，每行可以单独选怎么处理。选择会记住，下一篇用到同样的字时沿用。

备用字体规则

一行一条：原稿字体, … => 备用字体, …。字体名要写全名，不分大小写，* 匹配任意字符，# 开头的行是注释。备用字体插在字体栈里 sans-serif 等通用字体名之前。

取图地址

粘贴后，微信服务器会按这个地址到你电脑上取图，所以它要能从外网访问。工具只对外提供载入过的文章里的图片，关掉 serve.cmd 窗口就停止。
