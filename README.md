# html2gzh

把 HTML 页面转换为公众号编辑器能够保留的格式，粘贴为公众号图文。

公众号后台的编辑器会删除 `<style>`、class、position、CSS 变量、calc()、SVG 的 id 等内容，直接复制、粘贴网页，版面会错乱。html2gzh 把文章改写为编辑器能够保留的写法：

- 样式逐个写入元素的 style 属性
- 绝对定位改写为浮动与位移
- 随屏宽变化的尺寸改写为 cqw，成品随手机屏宽等比缩放
- SVG 与 SVG 动画改写为公众号能够保存的结构
- 可选：把指定的文字转为 SVG 路径，手机上的字形与原稿相同

转换后，在多个屏宽下与原稿逐元素比对，列出不一致的地方。文中的本地图片由本工具临时提供给微信服务器下载。

## 环境

| 项目 | 要求 |
| --- | --- |
| Node.js | 22.12 或更新版本 |
| 浏览器 | Chrome 或 Edge（界面、SVG 路径与测试均需使用）。未安装在默认位置时，用环境变量 `CHROME_PATH` 指定可执行文件 |
| 网络 | 文中有本地图片时，微信服务器必须能够从外网访问“取图地址”中的本机端口（默认 38960），见“取图地址” |

下载后，在目录中运行一次 `npm install`。

## 使用

以下以 Windows 为例；其他系统用 `node server.mjs <文章文件夹>` 代替 serve.cmd。

1. 把文章文件夹（或其中的 HTML 文件）拖放到 `serve.cmd` 上。浏览器会打开 `http://127.0.0.1:38961/` 并开始转换；默认浏览器不是 Chrome 或 Edge 时，把这个地址复制到其中打开。也可以先双击 `serve.cmd`，再在页面中拖入文件夹或粘贴路径。
2. 核对“原稿”与“公众号阅读页”两栏预览，以及侧栏中的“检查结果”。“必须处理”中的问题如不处理，草稿可能无法保存。
3. 点击“复制到剪贴板”，在公众号后台的正文中按 Ctrl+V。
4. 页面显示微信已下载全部图片后，点击两次“保存为草稿”（提示已保存后再点击一次）。第一次保存草稿时，编辑器尚未为图片添加尺寸信息，此时保存的正文在后台的“预览”中不显示图片。
5. 用后台的“预览”功能在手机上检查。

文章的 HTML 与其引用的图片、样式表放在同一个文件夹中（可以有子文件夹），文件夹以外的文件不会被读取。文件夹中有多个 HTML 文件时，把要使用的文件命名为 index.html，或直接给出它的路径。用路径打开时，原文件修改后会自动重新转换；拖入的文件夹修改后需要重新拖入。

## 取图地址

粘贴后，公众号后台把正文中的图片地址交给微信服务器，由微信服务器下载图片并转存到微信的服务器上，所以此时本地图片必须能从外网访问。页面中的“取图地址”有以下几项：

| 设置项 | 含义 |
| --- | --- |
| 本机端口 | 本工具提供图片的端口，默认 38960 |
| 公网地址 | 微信服务器访问的域名或 IP。留空时自动检测这台电脑所在网络的公网 IP |
| 公网端口 | 微信服务器访问的端口。留空时，协议为 http 则与本机端口相同，为 https 则使用 443 |
| 协议 | http 或 https。本工具只提供 http，https 由内网穿透工具或反向代理提供；自动检测公网 IP 时只能使用 http |

| 情形 | 做法 |
| --- | --- |
| 宽带有公网 IP | 在路由器上把“公网端口”转发到这台电脑的“本机端口”；“公网地址”可以留空。Windows 防火墙弹出提示时，允许 Node.js 在当前网络中通信 |
| 没有公网 IP（校园网、多数移动宽带） | 检测到的公网 IP 是学校或运营商的出口 IP，外网无法通过它访问这台电脑。用 frp、cpolar 等内网穿透工具把“本机端口”映射到外网，再把内网穿透工具提供的地址、端口与协议填入对应的设置项。以 http:// 或 https:// 开头的完整地址（如 `https://abc.example.com`）可以整体粘贴到“公网地址”，将自动拆分为协议、公网地址与公网端口 |
| 文中只有网络图片（以 http 开头的地址） | 不需要设置取图地址，微信服务器直接从原网址下载 |

保存后，本工具从这台电脑访问一次取图地址进行自测，页面打开期间每 5 分钟重新检测。内网穿透的地址通过自测，一般说明外网也能访问。部分路由器不支持从内网访问自己的公网地址，端口转发的地址因此可能显示“自测未通过”，但外网仍可能正常访问；可以先复制、粘贴一次，观察页面中显示的已下载图片数是否增加。修改设置后，请删除已粘贴的正文，重新复制、粘贴。

微信服务器下载每张图片最多等待约 0.5 秒，超时后隔 0.5 秒重试，连续三次超时即放弃，编辑器中这张图片的位置显示“系统繁忙”，草稿无法保存。能否在时限内下载完，取决于图片大小、同时下载的张数与这台电脑的上传速度；通过内网穿透提供图片时，下载速度还受内网穿透服务的带宽限制，通常更慢。因此超过 1 MB 的本地图片会列入检查结果（使用内网穿透时，需要压缩得更小）；粘贴后连续三次超时的图片，会在“复制到剪贴板”下方列出。

图片全部下载完成后，正文中的图片地址已替换为微信的地址，此时可以关闭本工具。

设置保存在本工具目录下的 `settings.json` 中。命令行参数 `--port N` 指定本机端口，优先于页面中的设置，此时页面端口为 N+1（也可以用 `--ui` 单独指定）；默认页面端口为 38961。

## 字体

电脑与手机自带的字体不同。原稿使用手机上没有的字体时，手机会改用其他字体显示；用 `@font-face` 引用的网页字体，在公众号正文中无法加载。“字体”卡片把文中用到的字体、字重与字号的组合逐行列出：

| 选项 | 效果 |
| --- | --- |
| 勾选 | 转为 SVG 路径（类似设计软件中的“转曲”）：手机上的字形与原稿相同，但在公众号后台无法再编辑；需要修改时，修改原稿后重新复制、粘贴 |
| 不勾选 | 保留为文字：按“备用字体规则”在字体栈中添加 iOS 与安卓自带的相近字体；手机上没有原稿字体时，显示为这些备用字体 |

- 字号统一按 iPhone 375 的正文宽度（335px）折算，可以按字号批量勾选。勾选按行记录：之后转换的文章中出现相同的字体、字重与字号组合时，沿用这一勾选。
- 同一段落的文字全部转为 SVG 路径或全部保留为文字，由段落中大部分文字所在的行是否勾选决定。状态列显示每一行的结果，鼠标悬停可查看转为路径的字数，以及其余的字保留为文字的原因。
- 系统字体的字形取自这台电脑上已安装的字体文件；通过 Adobe Fonts 等工具临时激活、没有正式安装的字体无法转为 SVG 路径。网页字体的字形取自原稿引用的字体文件：文章文件夹中的文件、data: 内嵌的字体，以及允许跨域读取的站外字体（如 Google Fonts）。可变字体、unicode-range 分片、size-adjust 与合成粗体、斜体均按 Chrome 的规则处理。
- 转为 SVG 路径的字只是图形，读者无法选中、复制。默认在路径上方放置一层位置相同的透明文字，读者因此仍可选中、复制这些字；这一项可以在“字体”卡片中关闭。

## 能够保留的效果

| 能够保留 | 说明 |
| --- | --- |
| 样式表中的样式 | 逐个写入 style 属性。包括外链样式表、@import、CSS 变量、::before/::after；@media 规则按所选屏宽对应的正文宽度判断是否生效 |
| 定位与层叠 | 绝对定位、相对定位、transform，多数情况下的 z-index |
| 等比缩放 | cqw、vw 等随屏宽变化的尺寸 |
| SVG | `<use>`/`<symbol>` 展开；渐变、滤镜、蒙版等依赖 id 的静态效果绘制为位图；SVG 内的 `<image>` 改为背景图 |
| SVG 动画 | SMIL 动画；SVG 中的 CSS 动画改写为 SMIL；公众号不支持的动画属性改用等效写法；同一元素上的点击、触摸触发 |
| 其他 | 不换行的文字、空的色块与线条 |

| 无法保留 | 说明 |
| --- | --- |
| HTML 元素上的 CSS 动画 | 停留在没有动画时的状态 |
| 交互样式 | :hover、:focus 等 |
| @container 规则 | 转换时忽略，相关样式缺失 |
| 互动元素 | 表单、音视频、iframe、canvas 会被删除，需要用后台自带的组件重新插入 |
| 站外链接 | 公众号正文只允许链接公众号文章，站外链接改为普通文字 |
| position: fixed | 随正文滚动 |
| 跨元素的 SVG 动画触发 | 由其他元素按 id 触发或衔接的动画（如 `begin="btn.click"`）不会播放 |

由固定值与比例值合成的尺寸（相当于 calc()）只在所选屏宽下完全精确，其他屏宽下按比例近似。比对使用这台电脑上的字体；没有转为 SVG 路径的字，在手机上没有原稿字体时显示为备用字体，字形与换行可能与原稿不同。

## 预览

“公众号阅读页”预览模拟公众号文章的阅读页：手机外壳、标题与作者行（占位内容）、正文区左右各 20px 的页边距、底栏。原稿有页面底色时，两侧页边距显示阅读页自身的底色，这一点无法通过正文修改，预览中可以直接看到。转换进度与错误提示显示在预览上层，不改变两栏的位置。

深色模式由微信开源的转换算法 [mp-darkmode](https://github.com/wechatjs/mp-darkmode) 生成，已与手机上的深色模式对照，颜色一致。

## 安全

- 页面端口只监听 127.0.0.1，并核对请求头中的 Host；改动状态的请求（打开文章、上传图片、修改取图地址等）只接受本页面发出的请求。
- “取图地址”中的本机端口对外网开放（微信服务器需要访问），不设认证，只提供已载入文章中引用的图片；文件名为内容的哈希值，外部难以猜测。关闭本工具后即停止提供。
- 文章中的 SVG 带有脚本时，直接打开它的图片地址，脚本也不会运行（响应带有 CSP sandbox）。
- 深色模式的转换在只允许脚本、与本页不同源的隐藏 iframe 中进行，文章内容无法访问本机接口。
- 字形服务的无头浏览器拦截所有网络请求，只返回已登记的字体文件。
- 为了确定公网 IP，本工具在启动时以及页面打开期间每 5 分钟访问几个查询 IP 的网站（myip.ipip.net、ip.sb 等，列表见 `server.mjs`）。外链样式表与站外字体由浏览器直接从原网址读取。

## 开发

原生 ES 模块，没有构建步骤。

| 目录 | 内容 |
| --- | --- |
| `ui/convert/` | 转换器，在浏览器中运行；`svg/` 是 SVG 与 SVG 动画的改写，`webfonts.js` 确定原稿实际使用的网页字体 |
| `ui/` | 界面；`phone.js` 是阅读页模拟，`vendor/` 是原样引入的第三方代码 |
| `server.mjs` | 本地服务（页面端口与取图用的本机端口） |
| `lib/` | SVG 路径使用的字形服务：无头 Chrome 确定每个字实际使用的字体，fontkit 读取字形 |
| `test/` | 端到端测试与测试稿 |
| `tools/` | 用于排查问题的脚本，用法写在各文件开头 |

`npm test` 用 `test/fixture`、`test/fixture-svg` 与 `test/fixture-webfont` 运行端到端测试：启动服务、转换、检查成品、在多个宽度下与原稿逐元素与逐像素比对、动画采样、字体表与阅读页模拟、取图地址、下载进度、端口安全。网页字体测试稿使用的字体文件，在测试时从 Windows 自带字体截取子集生成，不随仓库分发。也可以用自己的文章运行：`node test/e2e.mjs <文章路径> [--svg]`。测试稿按 Windows 10/11 自带的字体校准，在其他系统上比对结果会有出入。

公众号在服务端过滤保存的正文，规则可能变化。`tools/wxprobe.mjs` 生成一页带编号的测试内容，粘贴到测试草稿并保存后，与保存结果逐项比对，用于复核转换器所依据的规则；它的 `diff` 子命令比对整份成品。`tools/wxshot.mjs` 把公众号预览页与原稿逐像素比对，可以指定动画时刻与点击。
