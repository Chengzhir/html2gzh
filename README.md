# wxpaste

把本地 HTML 排版原样粘进公众号后台。

公众号后台的编辑器会删掉 `<style>`、class、position、CSS 变量、calc() 等，网页直接复制粘贴进去会走样。wxpaste 把文章转成编辑器能保留的写法：样式逐个写进元素的 style 属性，绝对定位改成浮动加位移，随屏宽缩放的尺寸写成 cqw，手机上没有的字体补上备用字体或画成 SVG 轮廓。转换完会在多个屏宽下和原稿逐元素比对，把对不上的地方列出来。文中的本地图片由它临时提供给微信服务器取走。

## 需要什么

- Node.js 22.12 或更新的版本。
- Chrome 或 Edge。界面在浏览器里运行，只在这两种浏览器上测过；"大字转轮廓"和测试也要用到它。装在默认位置以外时，设环境变量 `CHROME_PATH` 指向可执行文件。
- 文中有本地图片时，微信服务器要能从外网连到你电脑上的一个端口（默认 38960），见下面的"取图地址"。

下载本仓库后，在目录里运行一次 `npm install`。

## 使用

下面按 Windows 写；其他系统把"拖到 serve.cmd 上"换成在终端里运行 `node server.mjs <文章文件夹>`。

1. 把文章文件夹（或里面的 HTML 文件）拖到 `serve.cmd` 上。默认浏览器会打开 `http://127.0.0.1:38961/` 并开始转换；默认浏览器不是 Chrome 或 Edge 的话，把这个地址复制到它们里面打开。也可以先双击 `serve.cmd`，再在页面里拖入文件夹或粘贴路径。用路径打开时，原文件改了会自动重新转换；拖入的文件夹改了要重新拖入。
2. 看右边的两栏预览和左下的"检查结果"。"必须处理"的几项不处理，草稿可能存不了。
3. 点"复制到剪贴板"，到公众号后台的正文里按 Ctrl+V。
4. 等页面上的取图进度走完，然后点两次"保存为草稿"（提示已保存后再点一次）。第一次保存时编辑器还没给图片补上尺寸信息，存下的图片在预览里显示不出来。
5. 用后台的"预览"在手机上看一遍。

文章的 HTML 和它用到的图片、样式表要放在同一个文件夹里（可以分子文件夹），文件夹以外的文件不会被读取。一个文件夹里有多个 HTML 时，把要用的那个命名为 index.html，或者直接给出它的路径。

## 取图地址

粘贴之后，公众号后台会把正文里的图片地址交给微信服务器，由它下载并转存到微信自己的图床。所以文中的本地图片在这时必须能从外网访问。wxpaste 启动后会查出本机的公网 IP，并从外网回连自测，结果显示在页面的"取图地址"一栏。

- 宽带有公网 IP 时，在路由器上把 38960 端口转发到这台电脑。
- 没有公网 IP 时（校园网、很多移动宽带都是这样），用 frp、cpolar 等内网穿透工具把本机的 38960 端口映射出去，把得到的地址填进"没有公网 IP？用内网穿透"。
- 自测显示"不通"也可能只是路由器不支持从内网回连自己的公网地址，可以先复制粘贴试一次，看取图进度会不会动。
- 图片全部取走以后就可以关掉 wxpaste，正文里留下的是微信的图片地址。文中只有网络图片（http 开头的地址）时不需要这一步，微信会直接去原网址取。

端口可以用 `--port N` 换掉，页面端口随之变成 N+1（也可以用 `--ui` 单独指定）。

## 字体

公众号正文加载不了网页字体，读者手机上一般也没有电脑上的字体。界面的"字体"卡片里有两种方案：

- **备用字体**：全部保留为文字，按"备用字体规则"给字体栈补上 iOS 和安卓自带的相近字体。规则可以在界面里改。
- **大字转轮廓**：标题、编号等大字按原稿字形画成 SVG 图形（类似"转曲"），手机上和原稿一样，上面默认叠一层透明文字，读者仍能选中、复制、搜索。这些字在公众号后台改不了，要改就改原稿再复制一次。正文仍用备用字体。原稿字体要装在这台电脑上，用 `@font-face` 引用的网页字体画不了。

## 能保留什么

能保留的有：样式表（包括 CSS 变量、::before/::after，@media 按所选预览宽度取值）、绝对定位和相对定位、transform、多数情况下的 z-index、按屏宽等比缩放的排版（cqw、vw 等）、不换行的文字、空的色块和线条。

保留不了的有：动画（@keyframes）、:hover 等交互样式、@container 规则、表单和音视频等互动元素（微信会删掉，要用后台自带的组件重新插入）、站外链接（公众号正文只允许放公众号文章的链接，会改成普通文字）。position: fixed 的元素会跟着正文滚动。

由固定值和比例值合成的尺寸（相当于 calc()）只在所选预览宽度下完全精确，其他屏宽按比例近似。比对用的是这台电脑上的字体，手机上换成备用字体的地方，字形和换行仍可能不同。

## 安全

- 页面端口（默认 38961）只监听 127.0.0.1，并核对请求头里的 Host；会改动状态的请求（打开文章、登记图片等）只接受这个页面自己发的。
- 取图端口（默认 38960）对外网开放，因为微信服务器要来取图；它没有认证，只提供载入过的文章文件夹里被文章引用的图片，文件名是内容的哈希值。关掉 wxpaste 就停止。
- 文章里的 SVG 带脚本时，直接打开它的图片地址，脚本也不会运行（响应带 CSP sandbox）。
- 为了确定公网 IP，启动时和页面开着的时候每 5 分钟，会访问几个查 IP 的网站（myip.ipip.net、ip.sb 等，列表在 `server.mjs` 里）。

## 开发

代码是原生 ES 模块，没有构建步骤。`ui/convert/` 是转换器，在浏览器里运行；`server.mjs` 是本地服务；`lib/` 是"大字转轮廓"用的字形接口（无头 Chrome 加 fontkit）。

`npm test` 用 `test/fixture` 把两种字体方案各跑一遍端到端测试：起服务、转换、检查成品、在多个宽度下和原稿逐元素与逐像素比对、探测端口安全。也可以拿自己的文章跑：`node test/e2e.mjs <文章路径> [--svg]`。测试稿按 Windows 10/11 自带的字体校准，在其他系统上字体不同，比对结果会有出入。

`tools/` 里是排查问题用的脚本，比如把成品和公众号预览页逐像素对比（`wxshot.mjs`），用法写在各文件开头。
