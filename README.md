# html2gzh

把 HTML 页面转成公众号编辑器能保留的格式，粘贴为公众号图文。

公众号后台的编辑器会删掉 `<style>`、class、position、CSS 变量、calc()、SVG 的 id 等，网页直接复制粘贴会走样。html2gzh 把文章改写成编辑器能保留的写法：

- 样式逐个写进元素的 style 属性
- 绝对定位改成浮动加位移
- 随屏宽变化的尺寸写成 cqw，成品随手机屏宽等比缩放
- SVG 与 SVG 动画改写成公众号存得住的结构
- 可选：把指定的字转为 SVG 路径，手机上字形与原稿一致

转换后在多个屏宽下与原稿逐元素比对，列出对不上的地方。文中的本地图片由它临时提供给微信服务器取走。

## 环境

| 项目 | 要求 |
| --- | --- |
| Node.js | 22.12 或更新 |
| 浏览器 | Chrome 或 Edge（界面、SVG 路径与测试都用到）。不在默认位置时，用环境变量 `CHROME_PATH` 指定可执行文件 |
| 网络 | 文中有本地图片时，微信服务器要能从外网连到本机的取图端口（默认 38960），见“取图地址” |

下载后在目录里运行一次 `npm install`。

## 使用

以 Windows 为例；其他系统用 `node server.mjs <文章文件夹>` 代替 serve.cmd。

1. 把文章文件夹（或其中的 HTML 文件）拖到 `serve.cmd` 上。浏览器打开 `http://127.0.0.1:38961/` 并开始转换；默认浏览器不是 Chrome 或 Edge 时，把地址复制过去打开。也可以先双击 `serve.cmd`，再在页面里拖入文件夹或粘贴路径。
2. 核对右侧两栏预览和左侧的“检查结果”。“必须处理”的项不处理，草稿可能存不了。
3. 点“复制到剪贴板”，在公众号后台的正文里按 Ctrl+V。
4. 等取图进度走完，点两次“保存为草稿”（提示已保存后再点一次）。第一次保存时编辑器还没给图片补上尺寸信息，存下的图片在预览里不显示。
5. 用后台的“预览”在手机上检查。

文章的 HTML 与它用到的图片、样式表放在同一个文件夹里（可以有子文件夹），文件夹以外的文件不会被读取。文件夹里有多个 HTML 时，把要用的那个命名为 index.html，或直接给出它的路径。用路径打开时，原文件改动后自动重新转换；拖入的文件夹改动后要重新拖入。

## 取图地址

粘贴后，公众号后台把正文里的图片地址交给微信服务器，由它下载并转存到微信的图床，所以这时本地图片必须外网可达。html2gzh 启动后查出本机的公网 IP 并从外网回连自测，结果显示在页面的“取图地址”一栏。

| 情形 | 做法 |
| --- | --- |
| 宽带有公网 IP | 在路由器上把取图端口转发到本机 |
| 没有公网 IP（校园网、多数移动宽带） | 用 frp、cpolar 等内网穿透工具把取图端口映射出去，地址填进“没有公网 IP：使用内网穿透” |
| 自测“不通”，但可能只是路由器不支持从内网回连自己的公网地址 | 先复制粘贴一次，看取图进度是否变化 |
| 文中只有网络图片（http 开头的地址） | 不需要取图地址，微信直接从原网址取 |

图片全部取走后即可关闭 html2gzh，正文里留下的是微信的图片地址。

取图端口可以在页面里改，改后立即生效，和内网穿透地址一起存在工具目录的 `settings.json` 里。命令行 `--port N` 优先，此时页面端口为 N+1（也可用 `--ui` 单独指定）；默认页面端口 38961。

## 字体

公众号正文加载不了网页字体，读者手机上一般也没有电脑上的字体。“字体”卡片按字体、字重、字号逐行列出文中的字：

| 勾选 | 效果 |
| --- | --- |
| 勾选 | 转为 SVG 路径（类似“转曲”）：手机上字形与原稿一致，在公众号后台不能编辑，要改就改原稿再复制一次 |
| 不勾选 | 保留为文字：按“备用字体规则”补上 iOS 与安卓自带的相近字体 |

- 字号按 375 宽的 iPhone（正文 335px）折算；可以按字号批量勾选。勾选按行记住，下一篇用到同样的字时沿用。
- 一段文字整体转或整体不转，由这段里多数字所在的行决定。状态列显示每行实际转了多少字，悬停可看没转的原因。
- 原稿字体要装在这台电脑上。用 `@font-face` 引用的网页字体转不了。
- 路径上默认叠一层透明文字，读者仍能选中、复制。

## 能保留什么

| 能保留 | 说明 |
| --- | --- |
| 样式表 | 含 CSS 变量、::before/::after；@media 按所选预览屏宽取值 |
| 定位与层叠 | 绝对定位、相对定位、transform，多数情况下的 z-index |
| 等比缩放 | cqw、vw 等随屏宽变化的尺寸 |
| SVG | `<use>`/`<symbol>` 展开；渐变、滤镜、蒙版等依赖 id 的静态效果画成位图；SVG 内的 `<image>` 改成背景图 |
| SVG 动画 | SMIL 动画；SVG 里的 CSS 动画改写成 SMIL；公众号不收的动画属性换成等效写法；同一元素上的点击、触摸触发 |
| 其他 | 不换行的文字、空的色块与线条 |

| 保留不了 | 说明 |
| --- | --- |
| HTML 元素上的 CSS 动画 | 停在没有动画时的样子 |
| 交互样式 | :hover、:focus 等 |
| @container 规则 | 不套用 |
| 互动元素 | 表单、音视频、iframe、canvas 会被删掉，要用后台自带的组件重新插入 |
| 站外链接 | 公众号正文只允许链接公众号文章，改成普通文字 |
| position: fixed | 随正文滚动 |
| 跨元素的 SVG 动画触发 | 按 id 引用的触发与接力（如 `btn.click`）不播放 |

由固定值和比例值合成的尺寸（相当于 calc()）只在所选预览屏宽下完全精确，其他屏宽按比例近似。比对用的是这台电脑上的字体，不转为路径的字在手机上的字形与换行仍可能不同。

## 预览

右栏模拟公众号阅读页：手机外壳、标题与作者行（占位）、正文区左右各 20px 的页边距、底栏。原稿有页面底色时，两侧页边距显示阅读页自己的底色，这一点去不掉，预览里能直接看到。

深色模式用微信公开的转换算法 [mp-darkmode](https://github.com/wechatjs/mp-darkmode) 生成，与手机上的深色模式对照过。

## 安全

- 页面端口只监听 127.0.0.1，并核对请求头里的 Host；改动状态的请求（打开文章、登记图片、改端口等）只接受本页面发出的。
- 取图端口对外网开放（微信服务器要来取图），没有认证，只提供载入过的文章文件夹里被文章引用的图片，文件名是内容的哈希值。关闭 html2gzh 即停止。
- 文章里的 SVG 带脚本时，直接打开它的图片地址，脚本也不会运行（响应带 CSP sandbox）。
- 深色模式的转换在只允许脚本、与本页不同源的隐藏 iframe 里进行，文章内容访问不到本机接口。
- 为了确定公网 IP，启动时和页面开着时每 5 分钟访问几个查询 IP 的网站（myip.ipip.net、ip.sb 等，列表见 `server.mjs`）。

## 开发

原生 ES 模块，没有构建步骤。

| 目录 | 内容 |
| --- | --- |
| `ui/convert/` | 转换器，在浏览器里运行；`svg/` 是 SVG 与 SVG 动画的改写 |
| `ui/` | 界面；`phone.js` 是阅读页模拟，`vendor/` 是原样引入的第三方代码 |
| `server.mjs` | 本地服务（页面端口、取图端口） |
| `lib/` | SVG 路径用的字形接口（fontkit） |
| `test/` | 端到端测试与测试稿 |
| `tools/` | 排查用的脚本，用法写在各文件开头 |

`npm test` 用 `test/fixture` 与 `test/fixture-svg` 跑端到端测试：起服务、转换、检查成品、在多个宽度下与原稿逐元素与逐像素比对、动画采样、字体表与阅读页模拟、端口安全。也可以拿自己的文章跑：`node test/e2e.mjs <文章路径> [--svg]`。测试稿按 Windows 10/11 自带的字体校准，其他系统上比对结果会有出入。

公众号的存稿清洗规则在服务端，可能变化。`tools/wxprobe.mjs` 生成一页带编号的探针，贴进测试草稿后比对存下来的正文，用来复核转换器依据的规则。
